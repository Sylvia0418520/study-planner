# 我的作业清单（简约奶油风）

## 当前版本
- 添加、编辑、删除作业
- 课程、作业内容、截止日期和时间
- 按全部 / 未完成 / 即将截止 / 已完成筛选
- 自动按截止时间排序、逾期标记
- 本机浏览器 localStorage 保存
- JSON 备份导出；在备份按钮上长按/右键可导入备份
- 通知权限：应用打开期间检查并发出提醒

## 在 iPhone 上使用
这是一份可安装为主屏幕 Web App 的 PWA 源码。需要先部署到一个 HTTPS 静态网站（例如 GitHub Pages、Cloudflare Pages 或自己的 HTTPS 域名），然后用 iPhone Safari 打开网站，点“分享”→“添加到主屏幕”。

## 重要限制
纯本地网页无法保证 iPhone 在应用完全关闭时仍按自定义时间触发本地通知。当前版本只在页面运行时检查提醒。可靠的后台推送需要额外的 Push 服务端与订阅管理；本版本没有伪装成已具备该能力。

## 数据
任务仅保存在当前设备、当前浏览器/主屏幕 Web App 的本地存储中。清除网站数据、卸载或更换设备可能导致数据丢失。请定期使用“备份”导出 JSON 文件。
